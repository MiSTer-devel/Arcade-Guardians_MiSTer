# Upstream provenance

This file records the external sources used to build or document the core.
The repository contains no game ROM data.

## MiSTer framework

- Repository: `https://github.com/MiSTer-devel/Template_MiSTer.git`
- Base commit: `69b8a2acc6d84dd313b5abcba6a17155287ed3d8`
- Initial import: 2026-08-09
- License: GPL-3.0-or-later and per-file notices

The `sys/` directory is a vendored MiSTer framework snapshot. It matches the
recorded Template commit except for a five-line `sys/arcade_video.v` tie-off of
the optional `HDMI_FREEZE` interface in the legacy wrapper; the active core
does not use that wrapper's freeze engine. Core-specific video, analog, and CRT
geometry work remains outside the framework snapshot. Individual source
headers retain their original copyright and license notices.

## fx68k processor core

- Repository: `https://github.com/jtfpga/fx68k.git`
- Upstream commit: `1217ab8dc600de070c6adb71ea6fe69de8855362`
- Local path: `rtl/fx68k`
- License: GPL-3.0

The bundled Verilator-compatible SystemVerilog variant is adapted locally for
the TMP68301 subsystem. Jorge Cwik's README and GPL license are retained.

## CRT geometry

- Repository: `https://github.com/rmonic79/MiSTer-CRT-Adjust.git`
- Upstream commit inspected: `c682de9f4acc61d8f4c7779efb48149d3baa3a8e`
- Local paths: `rtl/crt_adjust.sv`, `rtl/crt_vsize.sv`
- License: GPL-3.0-or-later
- Retrieved: 2026-08-24

The local versions are adapted for Guardians' RGB555 pipeline, block-RAM
budget, native-sync cabinet mode, and optional retimed PVM mode. The original
authors and contributor are credited in the source headers and `CREDITS.md`.

## MAME hardware reference

- Repository: `https://github.com/mamedev/mame.git`
- MAME 0.287 tag commit: `e776c98438a465d3486c367cbad3777a6eb7902e`
- Driver: `src/mame/seta/seta2.cpp`
- Video device: `src/devices/video/x1_020_dx_101.cpp`
- Sound device: `src/devices/sound/x1_010.cpp`
- CPU peripheral device: `src/devices/cpu/m68000/tmp68301.cpp`

MAME was used as public hardware documentation and a behavioral reference. No
MAME source code is copied into this core. Hardware addresses, ROM metadata,
timing behavior, and device semantics are interoperability facts independently
implemented in HDL and XML. Guardians-specific raster behavior was validated
against original-PCB footage and hardware testing where the software model was
known to be incomplete.

## Cheat definitions

- Source: `https://www.mamecheat.co.uk/`
- Collection: Pugsy's MAME Cheat Collection
- Guardians definitions credited to: pasky13
- Engine model: `https://github.com/MiSTer-devel/Arcade-IremM92_MiSTer`
- Upstream engine author: Martin Donlon, based on handling by Kitrinx
- Upstream engine license: GPL-2.0-or-later

Only the documented Guardians addresses and values are expressed in the MRA;
the external Pugsy XML is not included. The local
`rtl/gd_mra_cheat_engine.sv` adapts the upstream MRA-code storage and matching
model for a 68000 big-endian bus and is distributed under GPL-3.0-or-later.

## Direct DDR ROM loading

- Repository: `https://github.com/MiSTer-devel/Arcade-IGSPGM_MiSTer.git`
- Upstream commit inspected: `6f757e42779a93e940134018c25f08aafaf95b93`
- Source: `rtl/rom_loader.sv`, `ddr_rom_loader_adaptor` at line 202
- Upstream author: Martin Donlon
- Upstream license: GPL-3.0-or-later

Guardians adapts the MRA direct-to-DDR staging/replay approach to its
35 MiB ROM layout. The local replay module preserves support for an ordinary
MiSTer ioctl stream and is credited in its source header and `CREDITS.md`.

## Generated FPGA IP

The PLL files below `rtl/pll*` and `sys/pll*` were generated by Intel/Altera
Quartus Prime and retain their generated notices. They are included solely to
reproduce the DE10-Nano build and remain subject to Intel's applicable FPGA IP
terms.
